# teng-chou-codes codage

Teng Chou is a logographic script of the Tantsou. This codage names each character by a code: a character by its morpheme in capitals (`WONG`), a stage of the tally by `TALLY1` to `TALLY5`, and a sign of the Jurthati syllabary by its syllable in lowercase (`ka`). Case separates a character from a sign that shares its spelling, so `KA` and `ka` are different characters. It is reached only between `⟦` and `⟧` of the [teng-chou encoding](teng-chou.md), and encodes no text of its own.

## Fonts

- Teng Chou (`teng-chou`), written left to right.

## Using it

A codage is a set of named sign rows included in an encoding. Its codes are written between `⟦` and `⟧`. Whitespace between codes only separates them, and decoding writes single spaces. Inside the markers only this codage's codes and notation are allowed, so a standard mark such as `,` is refused at its position. Outside them a code is ordinary roman. Asking for the codage as a whole-text encoding is an error that names the script encoding to use.

# semaron-codes codage

Semaron Kuriale is the Vylarian chancery hand, written left to right with capitals. This codage names each of its glyphs by a code: a letter by its name with `_MAJ` for the majuscule and `_MIN` for the minuscule (`CHEROLA_MIN`), a long vowel with `LONG_` before it (`LONG_ELZA_MAJ`), a digit as `DIGIT_ZERO` to `DIGIT_NINE`, and `POINT`, `CATCH` and `STRESS`. It is reached only between `⟦` and `⟧` of the [semaron](semaron.md) and [aelwythi-semaron](aelwythi-semaron.md) encodings, and encodes no text of its own.

## Fonts

- Semaron Kuriale (`semaron-kuriale`), written left to right.

## Using it

A codage is a set of named sign rows included in an encoding. Its codes are written between `⟦` and `⟧`. Whitespace between codes only separates them, and decoding writes single spaces. Inside the markers only this codage's codes and notation are allowed, so a standard mark such as `,` is refused at its position. Outside them a code is ordinary roman. Asking for the codage as a whole-text encoding is an error that names the script encoding to use.

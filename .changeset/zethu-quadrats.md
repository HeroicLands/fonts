- Khelathi Zethu Glyphs stacks signs into quadrats from joiners, segments and corner insertions typed between them, scaling each quadrat to fit one sign's square.
- A royal name typed between the begin and end enclosure controls is drawn inside a knotted cord, tied at the left, which stays whole on one line.
- Type the controls at the font's own code points, U+1EC60 to U+1EC6D, which work in browsers and Foundry; the Unicode controls are accepted for HarfBuzz tools only. The character chart lists them by name.
